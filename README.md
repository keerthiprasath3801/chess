# Stockfish 16 NNUE — Masterclass Chess Suite

A high-performance chess application powered by Stockfish 16 NNUE (WebAssembly), comprehensive opening explorer with 200+ openings across all families, 1,020+ Grandmaster game masterclasses with move-by-move AI annotations, and tactical traps training.

- **Live Frontend**: [frontend-ten-weld-86.vercel.app](https://frontend-ten-weld-86.vercel.app/)
- **Tech Stack**: React 18, TypeScript, Tailwind CSS, Chess.js, React-Chessboard, Stockfish 16 NNUE WASM Worker.
